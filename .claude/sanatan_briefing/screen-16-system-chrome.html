What this screen covers

Toast / Snackbar (used for bookmarks, undo, generic info)

  • Position: Bottom center, 60px from bottom of safe area (above bottom-nav on tab roots, near bottom on other screens).
  • Container: Pill-shaped 22px radius. Background dSurface2, 1px dDivider border. Width = content + padding, max 320px.
  • Content: Small saffron diamond ornament (5×5 rotated) + Lora serif 13.5px message + optional sans-serif uppercase action button on the right, separated by a thin vertical divider.
  • Motion: Slide-up 240ms easeOut + fade. Auto-dismiss after 3.5s. Slide-down 240ms easeIn on exit. New toast cancels old one (no queue).
  • Use cases: "Verse saved to your collection" (with Undo), "Note saved", "Bookmark removed", "Export failed — try again", "Daily reminder set for 7:00 AM".
  • Do NOT use for: Anything destructive (use dialog), anything blocking (use dialog), errors that need user action (use dialog or inline).

Confirmation dialog (destructive actions)

  • Scrim: 55% black, full-bleed, dismissible.
  • Card: 312px wide, centered, dSurface2, 1px dDivider, 12px radius. BindingLine motif at the top — small (sideGap 10px) — ties the dialog to the heritage vocabulary.
  • Title: Lora 19px w500 dCream, centered, 18px top padding.
  • Body: Lora italic 14px line-height 1.55 dText2, centered.
  • Action row: 1px top divider. Two equal-width buttons divided by a 1px vertical center divider. Left = Cancel (dText2 sans 13px w500). Right = destructive label in dIronRedBright sans 13px w600. Both 52px tall, no background.
  • Motion: Fade + scale 0.96→1.0 over 200ms.
  • Use cases: "Reset all data?", "Delete this bookmark?", "Clear AI chat history?", "Remove this note?"
  • Info variant: Same dialog but single full-width "OK" button in saffron at bottom. Used for "Export complete", "Reminder set", etc.

Time picker bottom sheet

  • Why custom: Material's default time picker doesn't speak the heritage vocabulary. The Lora serif numerals + saffron underline + AM/PM toggle in heritage style maintains visual continuity.
  • Sheet: Bottom sheet, 16px top corner radius, dSurface2. Drag handle (36×4px) at top.
  • Header: "Reminder time" Lora 17px + close ✕ icon.
  • Wheels: Two scroll wheels side by side with `:` separator. Each wheel 80px wide × 168px tall (3 visible rows × 56px). Selected row = 32px w500 saffron, unselected rows = 26px regular dText3. Saffron underline on the selected row — actually a 56px-tall pair of horizontal hairlines top + bottom, with the saffron-glowing top edge.
  • Minute increments: 5-minute steps (00, 05, 10, ...55). Reduces decision burden, matches "reminder" intent.
  • AM/PM toggle: Rounded segmented control below wheels. Selected segment has dSaffronGlow background + saffron text.
  • Actions: Cancel (secondary) + Save (saffron primary) right-aligned in action row.
  • Used in: Settings "Daily reminder" row + Onboarding step 2 reminder picker. Same sheet, same widget.

Splash / launch screen

  • Background: dBg (#0F0F0F) — dark always. The OS doesn't know the user's theme preference yet at splash time, and dark works for either.
  • Centered ॐ: Tiro Devanagari 96px in saffron with a 24px blur text-shadow glow. The mark of the app.
  • Wordmark: "सनातन" in Tiro Devanagari 26px in dSaffronDeep, 12px below the ॐ. Quiet, restrained — no English wordmark.
  • Loader dots: Three saffron dots at the bottom (80px from bottom) using the AIThinkingDots phase math. Visible when boot is slow (DB warmup, etc.). On fast devices the splash is gone before they finish one cycle.
  • Implementation: Use `flutter_native_splash` package for Android 12+ adaptive splash. Adaptive launcher icon reuses the same ॐ on a saffron-deep background with proper safe-zone padding.

Word callout (tap a Sanskrit word on Verse Detail)

  • Trigger: Tap a word in the Sanskrit verse. Tapped word gets a subtle saffron underline (4-color: 40% saffron) so the user sees what they hit.
  • Callout container: 240px wide, dSurface2 background, 1px dDivider border, 4px radius. Small 10×10 rotated arrow on the top edge pointing at the tapped word.
  • Content (top to bottom):
    • • Devanāgarī word in Tiro Sanskrit 22px saffron
    • • IAST transliteration in Lora italic 13px dText2
    • • Meaning in Lora 14px dText1 (1–2 lines, short)
    • • Grammar tag in small-caps sans 9.5px dText3 (e.g. "NOUN · NEUTER · LOC.SG")
  • Position: Anchored above the word with 4px gap. If insufficient space above, flip below. Arrow rotates accordingly.
  • Dismissal: Tap outside or tap the same word again. No close button.
  • Motion: 180ms fade + 0.96→1.0 scale from the anchor point.
  • Source: Word meanings come from a dictionary table seeded with common Sanskrit terms. Words without dictionary entries don't show underline on tap (just no-op).

Verse Detail edge cases

  • First verse of a chapter: Prev chevron at 40% opacity. Tap shows toast: "This is the first verse of the chapter."
  • Last verse of last chapter of a scripture: Next chevron at 40% opacity. ABOVE the bottom bar, show "You've finished the [Scripture Name]" in italic serif dText2, centered, with a small saffron diamond (10×10 rotated, 1px stroke) below it. No celebration screen, no confetti — restraint matches the app's voice.
  • Center label in bottom bar: "Bhagavad Gītā · End" in small-caps sans dText3 — replaces the usual "Ch X · v Y" pacing label.

AdMob placement — decision: HOME ONLY

  • Where: Bottom of Home screen, above the bottom navigation bar. 50px tall.
  • Wrapper: 1px top border (dDividerSoft) separating from content. Small "AD" label in 8.5px small-caps dText3 in the top-right of the ad slot — required by AdMob TOS and respects the user's intelligence.
  • NOT on: Verse Detail, Verse List, Chapter List, AI Chat, Search, Bookmarks, Festivals, Settings, Practice, Module Reader, Onboarding. Reading flow is ad-free. This is a deliberate restraint that signals respect.
  • Failure mode: If ad fails to load, collapse the banner area completely (don't leave empty space). The bottom-nav slides up to its normal position.
  • Test mode: Use AdMob test IDs in dev. Real ad unit IDs come from Saurabh's AdMob console.

Error states — AI Chat + Search Pandit + Export

  • AI Chat error message: Inline italic serif 14px dText2: "The connection couldn't reach the texts. The verses are still here, but the Pandit needs internet to think." Below it: small "RETRY" text button in saffron sans 12px tracked uppercase with a circular arrow icon. The message replaces what would have been the AI's response — same column position.
  • Search Pandit error: Same pattern within the "Ask the Pandit" answer card on Search screen.
  • Offline indicator: Small 10×10 iron-red-bright dot in the top-right corner of the chat input field send button when device is offline. Bordered with 2px of dBg so it sits cleanly on top of the saffron send button. Tap on the dot (or long-press the send button) shows tooltip: "AI Chat needs internet."
  • Export bookmarks failure: Shows info dialog (single OK button) with title "Export failed" and body "Couldn't write the file. Check storage permissions and try again."

Pull-to-refresh

  • Where: Library (refreshes recent additions), Chapter List (refreshes reading progress), Verse List (same), Bookmarks (refresh sort). Not on Home (everything is reactive already).
  • Indicator: Three saffron dots in AIThinkingDots pulse pattern, centered, 60px above the list when pulled. Replaces Material's default spinner — same vocabulary as AI thinking, which reinforces "the app is doing literary work" as opposed to "loading spinner."
  • Hint text: "release to refresh" in lowercase sans 11px tracked, dText3, below the dots. Appears when pull crosses the threshold.
  • Motion: Dots fade in as pull begins. Hint text fades in at threshold. On release: dots pulse for the duration of the refresh, hint text says "refreshing" briefly, then collapses.

Don'ts (across the whole system chrome layer)

  • ❌ Don't use Material's default toast/snackbar — design above. Material's slab-rectangular toast breaks the aesthetic.
  • ❌ Don't use Material's default time picker — too circular, too generic. Custom wheel picker matches the app.
  • ❌ Don't use Material's default alert dialog — no BindingLine motif means the dialog feels disconnected from the rest of the app.
  • ❌ Don't put ads on any reading surface. Free + ads only for the Home landing. Period.
  • ❌ Don't show "Loading..." spinners on reading surfaces. Skeleton states use the verse leaf shape with shimmer; non-reading surfaces use AIThinkingDots.
  • ❌ Don't show confetti or celebration animations anywhere. Even for "Module Complete" or "You finished the Gītā" — restraint is the brand.
